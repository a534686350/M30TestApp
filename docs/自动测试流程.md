# M30 自动测试流程

## 正常流程

1. 运行设置：选择方案、工位范围、采集模式和是否探漏。
2. 初始化设备：压力控制器、烘箱、DMM、采集板、通道板。
3. 设备初始化失败立即停止，不再带故障设备进入采集。
4. 探漏：逐阀加压、测量泄漏率、泄压；超限时由操作员选择停止或人工放行。
5. 温度点循环：
   - 设置烘箱温度并等待实际温度达到目标；
   - 保温；
   - 采集 UT、USC、ISC；
   - 逐压力点设置压力、等待稳定、保压、采集 USG；
   - 反向采集 USG_R；
   - 读取实际烘箱温度。
6. 计算指标：Offset、Span、NL、TCO、TCS、TCR、THO、THS、PH、TCT。
7. 按模板保存 `全性能.xlsx`，并执行泄压、停止烘箱。

## 故障处理规则

- COM、VISA/GPIB、DMM、采集板初始化失败：停止本轮，不生成“正常完成”的报告。
- 烘箱连续 3 次读温度失败或加热超时：停止本轮。
- 压力在稳定时间内未达到精度：停止本轮。
- 采集值为 `NaN`、`Infinity` 或绝对值超过 `Validation.DacMaxAbs`：该单元格标记为错误，不写入正常值。
- 探漏超限但人工选择继续：导出的“备注”列记录人工放行原因。

## 模式选择

运行设置中的 DMM 自动测试会实际执行 `Run:DmmAutoTest`；普通板卡测试执行 `Run:PerformanceTest`，长期稳定性执行 `Run:LongTermStabilityTest`。

## 现场复现建议

1. 测试前关闭旧程序实例，确认 `COM5` 未被其他串口工具占用。
2. 单独在手动调试页验证烘箱 `TEMP?`、压力控制器 `*IDN?`/读压、DMM `READ?`。
3. 先用 1 个工位跑完整流程，再扩大到全工位。
4. 每次只改变一个因素，并保留对应的 `run-YYYYMMDD.log`。
