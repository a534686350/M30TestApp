## 1. 需求口径

### 1.1 老板澄清（本方案依据）

1. **控制对象不同，不是一个东西**
   - 电路板测试 → 控制**气路阀门**（ValveRelay，走 DMM 继电器 + `[ValveSettings]`）
   - 万用表测试 → 控制**传感器电源开关**（973 通道三）
   - 两套映射必须物理隔离，不共用字段、不共用代码路径
2. **万用表自动测试最多 48 工位**
3. **一台 973 管 16 工位，三个通道全用上**：

   | 973 通道 | 范围 | 用途 |
   |---|---|---|
   | 通道一 | 101-116 | 采**电压**（mV） |
   | 通道二 | 201-216 | 采**电阻**（Ω） |
   | 通道三 | 301-316 | 每工位**独立电源开关** |
   | 通道三 | 319 / 320 | **总电源** |

4. **不采集 5 次原始值**（需求文档 2023/9/7 那条不做）

### 1.2 需求文档（`晶圆自动测试程序要求.docx`）补充

- 温度流程：25℃ 保温 t1 → 测 → 85℃ 保温 t2 → 重复 → 25℃ 保温 t3 → 重复 → 关烘箱 + 输出数据
- 上电：301~30X CLOSED + 319~320 CLOSED
- 电压采完 → 301~320 OPEN（断电）→ 再采 201~20X 电阻
- 压力点由压力控制器控制（文档未提气路阀门）

## 3. 目标设计

### 3.1 设备层：多台 DAQ973A

`Setting.ini` 配置（`StationProfile.Load` 扫描 `Device.Dmm*` 段，`IniFile.Sections` 已可枚举）：

```ini
[DefaultLoadClass]
Dmm = HW

[Device.Dmm]
Model   = DAQ973A
Address = USB0::0x2A8D::0x1301::MYxxxxxxxx::INSTR

[Device.Dmm2]
Model   = DAQ973A
Address = USB0::0x2A8D::0x1301::MYxxxxxxxx::INSTR

[Device.Dmm3]
Model   = DAQ973A
Address = USB0::0x2A8D::0x1301::MYxxxxxxxx::INSTR
```

改动点：

- `StationProfile`：新增 `List<DeviceProfile> DmmUnits`
- `TestSession`：新增 `IReadOnlyList<IDmm> Dmms`；`Dmm` 保持 `= Dmms[0]`（向后兼容，长期稳定性等老路径零改动）
- `TaskContext`：新增 `IReadOnlyList<IDmm> Dmms`；`Dmm` 保持
- `HwDmm` 已支持多实例（各自独立 `VisaSession` + Address），无需改

### 3.2 数据模型：工位表新增「电源开关」列

沿用「坐标X/坐标Y」的加列先例（老文件缺列按空处理），表头追加第 15 列：

```
工位,序列号,阀位,板卡位,板卡工位号,层数,夹具位,夹具工位号,压力控制器,数字万用表,通道,阀门,坐标X,坐标Y,电源开关
```

| 列 | 电路板采集 | 万用表采集 |
|---|---|---|
| 阀位 / 阀门 | 气路阀门号 / 继电器地址 | **留空** |
| 数字万用表 | 留空 | **设备号 1 / 2 / 3** |
| 通道 | 板卡通道 | **电压通道 101-116** |
| **电源开关**（新增） | 留空 | **301-316** |

电阻通道不落表，按公式 `200 + 工位在台内的序号(1-16)` 推导（与文档 201-216 一致）。

### 3.3 通道映射规则

48 工位按 16 个一组分到 3 台 973：

```
unit  = (slotNo - 1) / 16        → 0,1,2  → 973-1 / 973-2 / 973-3
local = (slotNo - 1) % 16        → 0..15
电压通道 = 101 + local
电阻通道 = 201 + local
电源开关 = 301 + local
总电源   = 319 / 320（每台独立）
```

### 3.4 执行流程

```
初始化：打开 N 台 973（各自 *IDN?）
探漏（勾选项，可跳过）
逐温度点 Tn：
    设烘箱 → 等待到达 → 保温 soak 分钟
    逐压力点 Pm：
        设压力 → 稳定 → 保压
        ── 上电：每台 973 闭合 301-316 + 319/320
        逐工位（跨 N 台）：读电压 ×1000 → {Tn}{Pm}_USG
        ── 断电：每台 973 断开 301-320
    逐工位读电阻 201-216 → {Tn}_DMM_R
    读烘箱温度 → {Tn}_OvenTemp（写全部工位）
下行回差（压力点 ≥2）：反向走压力点 → {Tn}{Pm}_USG_R
计算指标 → 保存 → 泄压 → 关烘箱
```

**全程不触发任何气路阀门继电器。**

## 5. 决策点（已全部拍板，2026-09-30）

| # | 问题 | 结论 |
|---|---|---|
| Q1 | 现场是 3 台 973 并行，还是先做 1 台 16 工位？ | **3 台，48 工位**。`MaxUnits = 3`，台数在「配置 → 设备」页下拉选 1-3 |
| Q2 | 电阻测量时机 | **电压上电测、电阻断电测**。采集项可分别勾选，跳过电压时连上电/断电都不执行 |
| Q3 | 总电源 319 / 320 语义 | **并联，上电时同时闭合**。通道号改为 `[DmmAutoTest] MasterChannels` 可配，默认 `319,320` |

已采用的默认假设：电压单位 mV（保留 ×1000）；每温度点测一次电阻写入 `{Tn}_DMM_R`；
48 工位**串行**读取（先保正确，不做 3 台并行加速）；上电/断电按「每个压力点一组」执行，不跨压力点保持。
