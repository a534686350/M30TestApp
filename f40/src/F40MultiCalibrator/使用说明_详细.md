# F40 多工位标定上位机 使用说明

## 1. 目录结构

- `F40MultiCalibrator.exe` / `软件补偿与F40标定.exe`：主程序，win-x86，自带 .NET 8 Desktop Runtime。
- `support\CalibrationL6.dll`：原 LabVIEW 标定算法 DLL，必须保留。
- `setting\Setting.ini`：设备、串口、GPIB、多DAQ、标定参数。
- `setting\Command.ini`：压力控制器、DAQ/DMM 指令模板，格式参考 M30TestApp。
- `logs\`：程序运行后自动生成日志。

## 2. 当前运行逻辑

1. 在【方案】或【工位/标定运行】选择原始 CSV。
2. 程序解析 CSV 里的 Slot、序列号、原补偿结果、7点原始数据和10个旧系数。
3. 加载后标定表固定为现场确认可用的4个通道32工位：`1-8`、`9-16`、`17-24`、`33-40`。当前已知4、7通道硬件异常，暂不放入默认标定表。
4. 如需把后续原始补偿数据复用到这32个工位，点击“复用原始数据”，按 `源Slot=目标Slot` 填写映射。
5. 根据【参数控制】里的多DAQ配置和“手动通道覆盖”，为每个 Slot 计算 DAQ 地址和采集通道。
6. 自动标定时：
   - 压控设置低点压力，等待稳定；
   - DAQ/DMM 读取该工位输出电压；
   - 压控设置满点压力，读取输出电压；
   - 按目标 0.5V / 4.5V 修正 BridgeDesired；
   - 调用 `CalibrationL6.dll!CalculateCoefficients` 生成10个系数；
   - 若勾选“写入板卡0x11”，执行现场验证后的原程序兼容写法：`0x63 固定 Slot1 进入写系数 -> 0x11 写目标 Slot 的10项系数 -> 0x61 固定 Slot1 退出写系数`；
   - 若勾选“写后复测”，复测低点、满点、中点，并计算线性。
7. 所有板卡 TX/RX、VISA 指令和结果都会写入 `logs`。

## 2.1 现场多通道标定策略

现场抓包和实机验证结论：

- 原标定程序虽然界面只做 Slot1，但代理验证后可写其他工位。
- 可靠写入策略不是把所有指令都改成目标 Slot，而是：
  - `0x63` 进入写系数：固定 `Slot1`
  - `0x11` 写10项系数：使用目标 `Slot`
  - `0x61` 退出写系数：固定 `Slot1`
- 已验证可用通道：
  - 通道1：`Slot 1-8`
  - 通道2：`Slot 9-16`
  - 通道3：`Slot 17-24`
  - 通道5：`Slot 33-40`
- 已知4、7通道硬件异常；6、8通道现场写入/收敛异常，当前版本默认不使用。

## 2.2 固定32工位和原始数据复用

加载CSV后，表格默认只显示并选中：

```text
1-8;9-16;17-24;33-40
```

如果需要把后续原始补偿数据填到这32个可写工位，点击“复用原始数据”，输入：

```text
41-48=1-8;57-64=33-40
```

格式说明：

- 左边是源 Slot，右边是目标 Slot。
- 支持单个和范围，例如 `41=1`、`41-48=1-8`。
- 源和目标数量必须一致。
- 复用内容包括 BridgeRaw、BridgeDesired、TempRaw、TempDesired 和10项原系数；目标 Slot、DAQ通道和是否勾选保持当前表格配置。
- 表格支持选中行后 `Ctrl+C` 复制，带表头，方便粘贴到 Excel 做人工核对。

## 2.3 手动采集通道覆盖

设备配置页新增“手动通道覆盖”，用于把当前标定 Slot 映射到你实际接线的 DAQ 通道。

常见写法：

```text
1=101;9=102;17=103;33=105
```

范围写法：

```text
1-20=101-120;21-40=201-220;41-60=301-320
```

说明：

- 左边是标定 Slot，右边是 DAQ 通道号。
- 覆盖命中时优先使用手动通道；未命中时继续使用默认 DAQ 映射。
- 使用手动覆盖时，即使板卡设置包含4/7通道而 DAQ 映射跳过4/7，程序也允许继续运行，只在日志提醒。

## 2.4 标定节奏

当前支持两种节奏：

- 单工位按顺序标定：每个工位独立完成低点、满点、写系数、复测，节奏最接近原标定程序。
- 统一加压批量标定：同一压力点批量扫多个工位，适合多工位效率优先场景。

## 3. 多台 DAQ973A 配置

在【参数控制】页的“多DAQ配置”中填写：

```ini
1-60=GPIB0::22::INSTR;DAQ973A60
61-120=GPIB0::23::INSTR;DAQ973A60
```

`DAQ973A60` 标准映射：

- 本地 Slot 1-20 -> 通道 101-120
- 本地 Slot 21-40 -> 通道 201-220
- 本地 Slot 41-60 -> 通道 301-320

例如：

- Slot1 -> GPIB0::22::INSTR / CH101
- Slot20 -> GPIB0::22::INSTR / CH120
- Slot21 -> GPIB0::22::INSTR / CH201
- Slot60 -> GPIB0::22::INSTR / CH320
- Slot61 -> GPIB0::23::INSTR / CH101

## 4. Command.ini 指令模板

【指令】页可编辑 `setting\Command.ini`，`9999` 或 `{0}` 会被程序替换：

- 压控 `SetPressure`：替换成 kPa 压力值。
- DAQ `Close/Open/SetVol`：替换成通道号。

常用 DAQ973A：

```ini
[Keysight-DAQ973A]
Open = "ROUT:OPEN (@9999)"
Close = "ROUT:CLOS (@9999)"
SetVol = "CONF:VOLT (@9999)"
ReadValue = "READ?"
```

## 5. 推荐测试顺序

1. 打开程序，先到【参数控制】确认 COM、GPIB、DAQ 配置。
2. 点【保存】，确认 `setting\Setting.ini` 已更新。
3. 到【工位/标定运行】加载 CSV，程序会自动固定到32个可用工位。
4. 如果要复用后续原始补偿数据，先点“复用原始数据”，按现场需要填写 `41-48=1-8;57-64=33-40` 这类映射。
5. 如实际接线不按默认通道走，在【设备配置】填写“手动通道覆盖”，再点“应用通道”。
6. 先只选择 1-2 个工位，取消“写入板卡0x11”，运行一次只验证压控和DAQ读数。
7. 再勾选“写入板卡0x11”，选择一个工位实写。
8. 确认日志和输出正常后，再批量跑固定32工位，或按现场选择其中部分工位。

## 6. F40 测试页

`F40测试` 读取 `setting\TestConfig` 中的原 ASLab 方案，只执行 DMM/DAQ 电压矩阵采集，不写编号、配置或系数。

- 原始 CSV 保留 `T1P1_V`、`T1P2_V` 等采样矩阵。
- 汇总 CSV 按原程序计算 `Offset`、`Span`、`PHO`、分升压/降压的 `NonLinear`、`THO/THS`、`TCO/TCS`、`TO/TS`。
- 原 INI 的 `测试项目参数.精度` 为 `TRUE` 时，按 `传感器精度等级` 生成精度 OK/NG；为 `FALSE` 时只输出统计结果，不伪造判定。
- 长漂、老化温循、`Read:CalCode`、`Read:RawCode` 或包含 `Write:` 的方案不属于无写入 DMM 矩阵，程序会阻止在该页启动。
- 找不到原测试 INI 时，默认点阵只用于界面预览，不能启动采集。
